# Hobby_Tracker — Клиентская часть

Данный репозиторий содержит клиентское приложение проекта **Hobby_Tracker**. Это desktop-часть системы, которая отвечает за графический интерфейс и взаимодействует с сервером посредством API-запросов для получения и синхронизации данных.

API: https://github.com/griy-rerere/hobby-tracker-api

## 📊 Графический интерфейс (GUI)

В приложении отображается подробная статистика пользователя, которая включает:
- Учет и разделение времени сессий;
- Сортировку данных по различным параметрам;
- Наглядные диаграммы и другие информационные графические элементы.

## 🔐 Регистрация и авторизация (JWT)

В проекте реализована система аутентификации пользователей на основе **JWT (Access/Refresh)**:

- **Регистрация:** Пользователь создает логин и пароль в GUI-формах приложения. Данные отправляются на сервер, где аккаунту присваивается уникальный ID для последующей валидации при входе.
- **Авторизация и запросы:** При входе клиент получает JWT-токены. Для доступа к защищенным данным приложение автоматически прикрепляет токен к заголовкам HTTP-запросов.
- **Обновление сессии:** Процесс валидации и обновления истекших токенов (Refresh) происходит автоматически на стороне клиента, незаметно для пользователя.


## 🛠 Технологический стек и Зависимости

- **Язык программирования:** C++
- **Фреймворк:** Qt (включая работу с сетью и графическим интерфейсом)
- **Система сборки:** CMake
- **Среда разработки:** Qt Creator

## 🚀 Установка и сборка проекта (Windows)

Для сборки проекта на Windows используется среда разработки **Qt Creator**. Все необходимые инструменты для компиляции и работы с сетью уже включены в состав фреймворка Qt.

### Шаг 1. Подготовка окружения
Для начала работы необходимо установить среду разработки и компилятор:
1. Скачайте онлайн-установщик **Qt** с официального сайта https://www.qt.io/development/download.(Используйте ВПН для входа на сайт и загрузку)
2. Откройте приложение, пройдите процесс авторизации в вашем аккаунте Qt.
3. В процессе установки выберите установку **Qt Creator** и необходимых компонентов для работы (например, компилятор MinGW или MSVC, а также CMake, если он не установлен в системе).

### Шаг 2. Клонирование проекта
Склонируйте данный репозиторий с исходным кодом:
```bash
git clone https://github.com/Zer0Dash/Desktop_Hobby_Tracker
cd Desktop_Hobby_Tracker
```

### Шаг 3. Настройка и Сборка проекта в Qt Creator

1. Откройте **Qt Creator** и нажмите **"File" -> "Open File or Project..."** (Файл -> Открыть файл или проект).
2. Выберите файл `CMakeLists.txt`, находящийся в корне папки `Desktop_Hobby_Tracker`.
3. Появится окно настройки проекта (Configure Project). Выберите нужный комплект сборки (Kit), соответствующий вашему установленному компилятору (например, Desktop Qt MinGW или MSVC).
4. Нажмите **"Configure Project"** (Сконфигурировать проект).
5. После успешной конфигурации нажмите кнопку **Build** (значок молотка в левом нижнем углу или `Ctrl+B`) для сборки проекта.
6. Для запуска приложения нажмите кнопку **Run** (зеленый треугольник или `Ctrl+R`).
